# 🔊 Soundboard

This little project was originally created for a **Science Slam** during the colloquium **"111 Jahre Kunstgeschichte an der Philipps-Universität Marburg"**. It provides an entertaining way to enhance presentations and events with fun sound effects.

🔗 [Official Event Website](https://www.uni-marburg.de/de/fb09/khi/aktuelles/nachrichten/111-jahre-kunstgeschichte-umr)

---

## 🎼 Features

- **12 Sound Effects** – Including classics like *Nein-Doch-Oh* from Louis de Funès and *Langweilig* from Homer Simpson.
- **Visual Button Design** – Intuitive UI for easy interaction.
- **Lightweight & Customizable** – Built with JavaScript, CSS, and HTML.
- **Easily Adaptable** – Modify sounds, design, or functionality as needed.

🔗 [Live Version of the Soundboard](khefele.github.io/Soundboard)

---

## 🛠️ Installation & Usage

1. **Clone or Download** the repository:
   ```
   git clone https://github.com/KHefele/soundboard.git
   ```
2. Open index.html in any modern web browser.
3. Enjoy! Click on the buttons to play different sound effects.

---

## 🎨 Customization

* Add or Replace Sounds: Simply update the audio files in the `SoundEffects/` folder.

* Modify Button Names: Edit the `const buttonNames` variable inside the `<script>` tag in the index.html file.

* Automatic Button Styling: Buttons are automatically generated and assigned new colors via `img.style.filter = "hue-rotate(...)"`, so no CSS changes are needed.
